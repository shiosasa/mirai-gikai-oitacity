# 議事録要約ページ専用指示書（committee-summary.md）

本書は、「みらいぎかいっち＠大分市」の議事録要約ページ（`/committees`）を作成・更新する際の個別ルールおよびプロンプトの仕様を定めるものである。作業時は上位の `master-workflow.md` の共通ルールを必ず遵守すること。

---

## 1. ページの基本仕様

### 【表側】サイト上の場所・役割
- **URLパス:** `/committees`
- **役割:** 会議全体の流れや決定事項、審議された議案、出席・欠席した議員（役職付き）、および生データを読みやすく整理した詳細議事録を掲示するページ[cite: 4]。
- **要約の切り替え構造（詳細ボタン）:**
  - **やさしい要約:** デフォルトで表示される、中学生でも分かるように専門用語を排除して噛み砕いた概要[cite: 3, 4]。
  - **詳細な要約:** 「詳細ボタン（切り替えスイッチ）」を押すことで切り替えて表示される、議論の背景や行政的経緯など専門用語も交えて深く掘り下げた詳しい解説[cite: 3, 4]。
  - **未登録時の挙動:** 「詳細な要約」のデータが存在しない場合は、ボタンをスライドした際に『詳しい要約は準備中です』と表示される仕様とする[cite: 3]。

### 【裏側】データベース構造
- **登録先テーブル:** `meetings` および `meeting_sessions` （※すべての生データの起点となるテーブル）

### 【リンク関係の仕組み】
- **出席議員・欠席議員のリンク:** 各議員のお名前から「議員紹介ページ」へリンクを張る（当局・行政側は含めない）[cite: 4]。
- **審議された議案のリンク:** 議案リストから、個別の「議案詳細ページ」へリンクを張る（存在する場合のみ）。

---

## 2. ライティング・ガイドライン（トーン＆マナー）
- **文体:** 読者に語りかける、柔らかく誠実な丁寧語を使用する[cite: 1]。
- **情報の密度と品質（情報の省略禁止）:** 議会や行政が公開している詳細情報を勝手に「省略」せず、必要な文脈をしっかり残す[cite: 1]。
- **改ざんの禁止:** 詳細議事録の作成にあたっては、元のテキストをベースに段落や見出しなどを綺麗に整えるのみとし、文章の意味の変更や改ざん（捏造・勝手な書き換え）は絶対にしないこと。
- **中国語漢字の排除:** `议`、`务`、`该` 等の中国語漢字は一切使用しないこと。

---

## 3. データベース / 項目定義（入力フォーマット）
議事録要約として登録・出力する際は、以下の項目構造（実際の画面の並び順）を厳守すること：

1. **会議名:** （例：「経済環境常任委員会」「本会議」など）[cite: 4]
2. **開催日:** `YYYY/MM/DD` 形式[cite: 4]
3. **やさしい要約:** デフォルト表示用。中学生でも一目で分かるよう、難しい言葉を噛み砕いた簡潔な概要[cite: 3, 4]
4. **詳細な要約:** 詳細ボタン切り替え用。深い解説データがある場合のみ入力（※未登録の場合は「詳しい要約は準備中です」の表示となる）[cite: 3, 4]
5. **決定事項:** 会議で決定した内容の箇条書き[cite: 4]
6. **審議された議案（あれば）:** 議案番号・議案名・ステータス等（※議案詳細ページへのリンクに対応）
7. **出席議員・欠席議員:**
   - 議員のみを対象とし、委員長・副委員長・委員などの役職を明記する[cite: 4]。
   - 議員紹介ページへのリンクおよびバッジ表示に対応させる[cite: 4]。
   - （※当局・行政側のメンバーはここには含めない）[cite: 4]
8. **詳細議事録:**
   - 議事録の元のテキストをベースにしつつ、市民が読みやすいように段落や見出しなどを綺麗に整理・整形したもの（※文章の改ざんは一切行わない）[cite: 4]。

（ここに議事録のテキストを貼り付け）
