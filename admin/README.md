## 大分市版の管理画面

ログイン後はダッシュボードを表示します。サイドバーの「コンテンツ更新」から、
議事録要約・議案カード・トピックスカード・記者会見・市長提案理由・議員の発言・
お知らせの管理画面へ移動できます。「議員紹介」は従来の議員名鑑編集です。

「インタビュー確認・公開」から回答・チャット履歴を確認し、本人同意などの条件を
満たした要約を記事の「生の声」に採用できます。既存のインタビュー設定も維持しています。

- 議事録要約：会議を選択し、開催日ごとの要約・決定事項・出席者・議案・原文を編集。
- 記者会見：下書きを作成し、発表・質疑・発言を個別に保存してから公開。
- 市長提案理由：対象本会議の原文・要約・公式出典URLを編集。
- 議事録要約と提案理由は下書きがなく、保存で公開サイトに反映され得ます。
- 本番DBを参照する環境では、確認目的でも保存・削除をしないでください。

### 議案カード・トピックス記事の更新

公開状態の変更とは別に、本文を編集できます。

- 議案一覧の「カード・本文を編集」：公開カードに使う議事録の議案名・番号・
  短い説明と、詳細ページの本文を編集します。説明は議事録ごとに保存します。
  複数議事録の説明がある場合は、公開サイトが最初に取得した空欄でない説明を
  採用するため、それぞれ確認してください。他の議案や採決結果は維持します。
- 詳細本文：既存の見出しごとに本文を編集でき、Markdown全体の編集にも切り替えられます。
  「ふつう」と「難しい」は一括保存します。空欄は保存され、以前の文章を消せます。
  保存前のプレビューは確認用です。実際の公開表示は難易度と既存キャッシュに依存します。
- 審議状況・画像・カテゴリ：従来の基本情報・タグ編集へ移動します。
  画像の選択・解除だけでは公開中の画像ファイルを削除しません。
- トピックス一覧の「記事の内容を編集」：タイトル、カテゴリ、状況、３つの要点、
  詳細、理由、重要ポイント、対象者、期待・懸念の声、関連リンク、議決日を編集します。
  公開サイトが優先表示する`proposals`と`bill_articles`を同一トランザクションで保存します。
  公開本文の参照先は`bill_articles.bill_id`で、別用途の`proposal_id`は変更しません。
  タイトル変更前に旧インタビューリンクをIDとして固定し、既存ID・回答・
  出典の議事録・公開状態・初回公開日を維持します。
- AIインタビューの本人回答は編集しません。「インタビュー確認・公開」で確認・採用します。

トピックス本文の保存には、承認後に
`supabase/migrations/20261103080000_add_admin_topic_content_save.sql`の適用が必要です。
Service Roleのみが実行できる保存関数の追加で、既存データの一括変更はありません。
関数未適用の場合は保存がエラーになります。DB適用後に管理画面をデプロイしてください。
本番への適用・保存テストは、必ず事前確認を取ってください。

SQLの回帰テストは開発依存のPGlite（実際のPostgreSQLエンジン）で、
両テーブルの整合性、ロールバック、競合、インタビューID・公開日・出典の保持を確認します。
本番DBへは接続しません。

議案カードの一覧・重複候補・注目議案の評価対象には議案だけを表示し、
トピックス用の受け皿（`bills.source = topic`）は含めません。
公開サイトと共通の絞り込みを使用し、`source` 未適用時は
`proposals` と同名の受け皿を除外します。

### 管理機能の有効化

既存のDB項目を確認したうえで、管理画面用Vercelプロジェクトの
Productionに以下をConfigとして設定し、再デプロイしてください。
公開サイト用プロジェクトの設定は別です。この設定自体はデータを公開しません。

| 機能 | Key | Value |
| --- | --- | --- |
| トピックス | `TOPIC_PUBLICATION_ENABLED` | `true` |
| 議員の発言 | `POLITICIAN_SPEECH_MODE` | `database` |
| お知らせ | `SITE_INFORMATION_ENABLED` | `true` |

トピックスは`bill_articles`の公開状態・初回公開日時と、
`proposals.published_date`が必要です。議員の発言は
`politician_speech_highlights`、お知らせは`site_information`を使用します。
項目が既にある環境には、重ねてDB変更を適用しません。
公開操作時は各画面で内容と公開条件を確認してください。

詳細は[管理画面再編設計・運用](../docs/20261103_0100_大分市版管理画面再編設計.md)を参照してください。

## Getting Started

First, run the development server:

```bash
pnpm dev
```

Open [http://localhost:3001](http://localhost:3001) with your browser to see the result.
