# 大分市の事務事業評価PDF

大分市版の資料・変換・登録手順は未確認。旧福岡県版のURLやスクリプトを転用しない。

1. 大分市公式の対象年度・評価書を確認し、事業名、評価項目、数値、ページ、出典URLを対応付ける。
2. 現行の事務事業評価ページ、保存先、スキーマ、既存データ、変換処理を調査する。対応方法が不明ならユーザーに相談する。
3. 抽出結果を元資料と照合し、欠落や判読不能な項目を報告する。AI生成文があれば登録前に全文の承認を得る。
4. 本番DBを変更する前に対象・差分を提示して承認を得て、[db-access](../db-access/SKILL.md) に従う。
