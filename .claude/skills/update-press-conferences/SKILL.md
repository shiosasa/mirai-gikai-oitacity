# 大分市長の記者会見 更新

詳細は [市長提案理由と記者会見の更新手順](../../../docs/20261101_2212_市長提案理由と記者会見の更新手順.md) を参照する。DB接続は [db-access](../db-access/SKILL.md) に従う。

1. 大分市公式の会見ページ・配付資料・対象動画を確認し、既存会見の日付・`slug`・状態・項目と照合する。動画や質疑を確認できなければ推測で作らない。
2. 発表・質疑の見出しと要約全文、公式ページ・PDF・動画との対応、字幕や音声の未確認箇所をユーザーに提示し、内容の承認を得る。
3. 本番DB書き込みの別途承認を得た後、新規会見は `draft` で登録する。公開済み会見の編集は本番に反映され得る。既存データの削除・再投入や盲目的な再送はしない。
4. 下書きの確認は `MAYOR_LOCAL_DRAFT_PREVIEW=1` 等の条件を満たすローカル開発環境の市長ページで行う。Vercelプレビューと通常の会見一覧は `published` のみ表示する。
5. 公開には別途明示承認を得て、対象ID・状態・承認済みの内容を再照合する。`published` に変更後、市長ページと会見一覧・詳細、資料・動画を確認する。

`press_conference_turns` の市長はDB上の既存値 `governor` で表現され、画面では「市長」と表示される。要約のみの場合に、確認していない発言のやりとりを作らない。
