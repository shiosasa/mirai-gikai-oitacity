# 大分市の委員会議事録 取得

大分市版の取得・投入手順は未確認。旧福岡県版の会議録サイトやスクリプトを実行しない。

1. 大分市公式の会議録と対象の会議・日時・議題を特定し、利用条件と原文の取得方法を確認する。
2. 現行の議事録関連テーブル、既存データ、取得・投入処理を調査する。対象の重複や他会議との取り違えを防ぎ、方法が不明ならユーザーに相談する。
3. DB書き込みの対象・件数を示して承認を得た後、[db-access](../db-access/SKILL.md) に従う。既存の議事録を一括削除して入れ直さない。
4. わかりやすい表現・要約の作成は [committee-minutes-ai](../committee-minutes-ai/SKILL.md) を参照する。
