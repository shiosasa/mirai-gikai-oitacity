# 大分市の委員会議事録 要約

旧福岡県版のDB・投入スクリプトは大分市版で未確認のため使用しない。[全体共通ルール](../../../docs/20261021_1800_全体共通ルールmaster-workflow.md) と [議事録要約ページ専用指示書](../../../docs/20261021_1805_議事録要約ページ専用指示書committee-summary.md) を確認し、現行のデータ構造と対象議事録を照合する。

1. 大分市公式の原文、会議・議題・発言者を特定し、他の議題の内容が混ざらないよう要約する。
2. 日本語、数字、固有名詞、発言者、原文との整合を確認し、AI生成文の全文と出典をユーザーに提示して承認を得る。
3. 登録方法が未確認なら調査してユーザーに相談する。本番DBに書く場合は内容の承認とは別に許可を得て、[db-access](../db-access/SKILL.md) に従う。
4. 登録後は対象会議の画面で見出し・要約・原文への対応を確認し、未確認箇所を報告する。
