# 市長の提案理由 更新

[市長提案理由と記者会見の更新手順](../../../docs/20261101_2212_市長提案理由と記者会見の更新手順.md) の「提案理由」を参照する。DB接続は [db-access](../db-access/SKILL.md) に従う。

1. 対象会期の大分市公式原文と `meetings` の既存会議を照合する。原文・要約・公式URLは同じ会議に対応させる。
2. 公式原文に基づく要約全文と出典を提示し、内容の承認を得る。提案を決定済みと書かず、数字・年度・名称・会期の混入を確認する。
3. 本番DB書き込みの明示承認後、対象IDと現在値を再確認して必要なフィールドだけ更新し、読み直して照合する。
4. 提案理由に下書き状態はない。共有DBを更新すると本番にも表示され得るため、画面確認だけを目的に本番DBへ書き込まない。
5. `/politicians/mayor` で要約・開閉・公式リンクを確認する。原文そのものは画面に載せない。
