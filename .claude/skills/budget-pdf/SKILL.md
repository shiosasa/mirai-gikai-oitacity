# 大分市の予算PDF

大分市版のPDF取得・変換・登録手順は未確認。旧福岡県版のURLやスクリプトを転用せず、次を確認してから進める。

1. 大分市公式の対象年度・会計・資料を特定し、表、単位、ページ範囲、元資料のURLを確認する。
2. 現行の予算ページ、保存先、スキーマ、既存データ、利用可能な変換処理を調査する。対応方法が不明ならユーザーに相談し、別地域のデータを投入しない。
3. 抽出結果は元PDFと件数・金額・項目の対応を照合し、読み取れない箇所を明示する。AI生成文があれば全文の承認を得る。
4. 本番DBを変更する前に対象・差分を提示して承認を得て、[db-access](../db-access/SKILL.md) に従う。
