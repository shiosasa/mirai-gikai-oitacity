# 大分市議会の一般質問

大分市版の取得・パース・投入手順は未確認。旧福岡県版のプロジェクトやパーサーを転用しない。

1. 大分市公式の対象会期・一般質問・出典を確認する。文字コードや話者の区切りは実際の資料に基づいて判断する。
2. 現行のページ、保存先、スキーマ、既存データ、利用可能なパーサーを調査する。会期・質問者・答弁者を取り違えないよう照合し、方法が不明ならユーザーに相談する。
3. AI生成文があれば全文と出典を提示して承認を得る。本番DBに書く場合は対象・件数・差分を示して別途許可を得て、[db-access](../db-access/SKILL.md) に従う。
4. 既存データを無断で削除せず、登録後は件数・内容・画面表示を確認する。
