# 大分市版 議案のタグ付け

DB接続・本番書き込みの承認は [db-access](../db-access/SKILL.md) に従う。大分市版の現在のタグ名・ID・表示優先度を読み取り、他地域のタグやプロジェクト情報を転用しない。

## 仕組み

- タグマスタは `tags`、議案との関連は `bills_tags`。タグのラベルは `tags.label` で、IDや `featured_priority` は環境ごとに確認する。
- トップの注目議案は `bills.is_featured = true` を条件とし、タグ別議案は `bills.publish_status = 'published'` を条件とする。どちらも表示難易度に一致する `bill_contents` が必要。
- タグ別セクションは、`tags.featured_priority` がNULLでないタグを昇順に表示する。タグを追加しただけで必ず表示されるとは限らない。
- 議案ピックアップのカテゴリバッジは、対応する記事の `bill_articles.source_refs` から得る記事カテゴリと、議案に関連する `bills_tags` のラベルの両方を使う。記事がなくても対応するタグで補えるが、ラベルは実装の `BILL_PICKUP_CATEGORIES` に一致する必要がある。
- 議案とトピックスを混同しない。アプリから議案を取得するときは `getMeetingBillFilter()` と `applyMeetingBillFilter()` を使い、`source='topic'` のインタビュー用データを議案としてタグ付けしない。

実装は [議案リポジトリ](../../../web/src/features/bills/server/repositories/bill-repository.ts) と [議案ピックアップのカテゴリ処理](../../../web/src/features/committee-minutes/shared/utils/build-bill-pickup-items.ts) を参照する。

## 手順

1. 対象の正式名称、要約、会議・議案ID、現在のタグ、記事との対応を読み取り、対象が実際の議案であることを確認する。タグ名とIDは大分市版DBから確認する。
2. 議案の中身に合う既存タグを選ぶ。正式名称が形式的なときは、例えば学校用端末の処分なら資料・要約に基づいて「子育て・教育」を検討する。内容に合わないタグを無理に付けない。
3. 変更する議案・タグ・表示への影響をユーザーに示し、本番DBの書き込み承認を得る。`bills_tags` の既存の組み合わせを確認し、重複登録や他のタグの削除をしない。
4. 対象の関連だけを追加し、更新件数と保存された組み合わせを読み直す。画面で議案ピックアップのバッジを確認する。トップにも表示したい場合は、タグの優先度・議案の公開条件と実際の表示を別に確認する。
5. 表示されない場合はラベル、記事参照、公開状態、カテゴリの対象範囲、キャッシュを確認する。確認のためにタグ設定や既存データをまとめて変更しない。
